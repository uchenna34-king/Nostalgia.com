<objective>
Re-architect the catalog data model so it scales to thousands of products with
per-product image sets and curated collections — the structural foundation for the
whole phase (D-06, D-09, D-10, D-11, CATL-01). Migrate the JSON `images` string
column on `Product` into an ordered related `ProductImage` table, add a `Collection`
entity (curated grouping separate from category) with an implicit many-to-many
product relation, add optional `materials`/`care` richer-detail columns now (cheaper
than a later re-migration, per CATL-01's "no redesign" goal and RESEARCH Open
Question 2), and add indexes for the fields filter/sort will hit. Update `seed.ts`
to write the new shape and seed two starter collections, and update `lib/products.ts`
so the existing storefront keeps rendering unchanged.

Purpose: Give every downstream plan a scalable schema; nothing else in Phase 8 can
be built until images are a relation and collections exist.
Output: Updated Prisma schema (pushed + generated), a reseeded catalog, and a
`lib/products.ts` that maps images from the relation to the stable `Product` type.
</objective>
