<objective>
Build the analytics foundation and its consent gate for the storefront (D-08, D-10, UI-SPEC §4). Install Vercel Web Analytics + Speed Insights, add a provider-agnostic `lib/analytics.ts` `trackEvent()` that emits only after consent, build the `ConsentBanner` client island, and wire an `AnalyticsGate` in `Providers.tsx` that mounts the analytics components only after the shopper accepts.

Purpose: ANLY-01 requires key storefront events to be tracked behind a consent banner. This plan lays the foundation — the abstraction, the consent state machine, the banner UI, and the gated mount — so that the five funnel call sites (10-10) have a ready `trackEvent()` to call. No event call sites are wired here (that is 10-10).

Output: `lib/analytics.ts`, `components/ConsentBanner.tsx`, an extended `components/Providers.tsx`, and the two Vercel packages installed. Turns `tests/analytics.test.ts` and `tests/a11y.test.tsx -t ConsentBanner` (both scaffolded RED by 10-01) green; `tsc` clean; dev-runnable.
</objective>
