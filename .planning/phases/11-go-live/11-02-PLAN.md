<objective>
Close the open authentication door before Phase 11 puts this app on a public URL, without taking away the demo login that UAT depends on.

The `demo` CredentialsProvider in `lib/auth.ts` currently sits **outside** the `hasGoogle` guard, so it is registered unconditionally. Its `authorize()` upserts and returns whatever email the caller supplies, with no secret of any kind. On a publicly reachable deployment that means any visitor can authenticate as any email address — including `OWNER_EMAIL`, which `requireOwner()` in `lib/admin.ts` accepts as the sole credential for `/admin`.

This plan gates that provider behind `ALLOW_DEMO_LOGIN` using strict `=== "true"` string equality (D-03), extracts the gate into a Prisma-free `buildProviderFlags` helper so the truth table is provable by unit test rather than by inspection, and delivers the UI-SPEC Contract 8 sign-in layout so the page reads as intentional both with two providers (UAT) and with Google alone (go-live).

Purpose: LIVE-01 — real identity on a public URL, with no unauthenticated path to owner privileges.
Output: one new pure module, one new test file, three modified files.

**Per D-11, `ALLOW_DEMO_LOGIN` stays TRUE for the UAT deployment.** This plan builds the switch and proves both positions work. Flipping it to `false` is a deferred go-live action owned by plan 11-08's pre-launch checklist — do not plan, perform, or recommend that flip here.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public internet -> `/api/auth/callback/demo` | Anonymous, unauthenticated POST from any origin on the public UAT URL. No secret is required by the demo provider's `authorize()`. |
| `authorize()` -> session JWT | An attacker-chosen email becomes the identity carried in the signed session token. |
| session JWT -> `/admin` via `requireOwner()` | `lib/admin.ts` treats a case-insensitive match against `OWNER_EMAIL` as sufficient authorization. Identity is the only gate. |
| server env -> client bundle (`/signin` props) | `demoLoginEnabled` and `ownerEmail` cross from server config into publicly rendered markup. |
