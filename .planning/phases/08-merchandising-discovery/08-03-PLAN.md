<objective>
Build the scalable, testable heart of discovery: a pure `lib/catalog.ts` module that
translates untrusted URL query params into Prisma `where`/`orderBy`/`skip`/`take`
pieces, plus the `getCatalog`/`getCollections`/`getCollectionBySlug` data functions
that execute them as single indexed SQL queries with a matching count for pagination
(D-01, D-03, D-04, D-07, CATL-01). All the query logic — search across name +
description + category, AND-combined category/size/price filters, the four sort
options, page clamping, price parsing, and pagination math — lives in pure functions
so it is unit-tested with Vitest without a database or browser (per the VALIDATION
strategy). SQLite's real limits are baked in and isolated: case-sensitive `contains`
(no `mode: "insensitive"`), and a quote-guarded string `contains` for the JSON `sizes`
column (no `array_contains`) — both flagged as Postgres-migratable in Phase 11.

Purpose: Prove DISC-01/02/03 and CATL-01 query behavior deterministically before any
UI is wired, and give the shop + collection pages one query path.
Output: `lib/catalog.ts`, a green `tests/catalog.test.ts`, and the paginated/collection
query functions in `lib/products.ts`.
</objective>
