<objective>
Turn `/shop` into the URL-driven, live search/filter/sort/paginate experience the
phase promises (DISC-01/02/03, CATL-01, D-01..D-07). The page stays an async Server
Component that reads `searchParams` and fetches one page via `getCatalog`; small
`"use client"` islands (`SearchBox`, `FilterPanel`, `Pagination`) own the interactive
URL writes using `useSearchParams`/`useRouter`/`usePathname` and the researched
`use-debounce` pattern. Every island is wrapped in `<Suspense>` so the production
build does not fail (Pitfall 1 — this is verified with a real `next build`, not just
dev). The existing category pills stay as a fast path (D-05), and every filter/search
change resets `?page=` to 1 (Pitfall 5).

Purpose: Deliver the customer-facing discovery surface on top of the proven query
builder, shareable/back-button-friendly via URL state.
Output: three client islands, a shared `ProductGrid`, and a rewritten `app/shop/page.tsx`.
</objective>
