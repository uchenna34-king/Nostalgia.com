Deliver the wishlist state layer as a structural sibling of the cart (D-13, D-14,
WISH-01): a pure reducer module with Vitest coverage, a localStorage-backed
`WishlistContext` cloned from `CartContext`, a reusable `WishlistButton`, and the
`Providers` wiring. Per D-13 the wishlist persists in localStorage for everyone (no
login) and mirrors the existing cart pattern; per RESEARCH Open Question 1 and D-13's

directly from context with no extra server fetch. All mutation logic (add/remove/
toggle/idempotency) is a pure module so it is unit-tested without a browser.

proven deterministically before the UI surfaces (cards/PDP/page) consume it.

`WishlistButton`, and updated `Providers`.
